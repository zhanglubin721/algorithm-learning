# LC127 单词接龙

Word Ladder · Hard · 图的广度优先搜索

## 题意

每步只替换一个字符，中间词及结束词必须在词表中，求从起点词变到终点词的最短序列长度；无法到达返回0。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;
class Solution {
    public int ladderLength(String beginWord, String endWord, List<String> wordList) { throw new UnsupportedOperationException("TODO"); }
}
```

输入依次为：beginWord（string）, endWord（string）, wordList（list<string>）。

## 约束要点

- 对于 1 <= i <= k 时，每个 si 都在 wordList 中。注意， beginWord 不需要在 wordList 中。
- 1 <= beginWord.length <= 10
- 1 <= wordList.length <= 5000
- wordList 中的所有字符串 互不相同

## 示例输入

示例1

```text
"hit"
"cog"
["hot","dot","dog","lot","log","cog"]
```

示例2

```text
"hit"
"cog"
["hot","dot","dog","lot","log"]
```
