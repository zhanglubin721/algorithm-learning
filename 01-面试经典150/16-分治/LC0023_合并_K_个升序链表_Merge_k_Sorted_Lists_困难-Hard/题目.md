# LC23 合并 K 个升序链表

Merge k Sorted Lists · Hard · 分治

## 题意

把多条升序单链表合并为一条升序链表。

## 约束要点

- 0 <= k <= 10^4
- 0 <= lists[i].length <= 500
- -10^4 <= lists[i][j] <= 10^4
- lists[i] 按 升序 排列
