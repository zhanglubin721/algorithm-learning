# LC427 建立四叉树

Construct Quad Tree · Medium · 分治

## 题意

把0/1方阵构造为四叉树。全同值区域成为叶子，否则分成四个等大区域递归构造；非叶子的val不参与判定。

- n == 2x 其中 0 <= x <= 6
