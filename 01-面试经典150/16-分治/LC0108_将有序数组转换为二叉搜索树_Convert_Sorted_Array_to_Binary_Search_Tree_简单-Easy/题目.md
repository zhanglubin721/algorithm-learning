# LC108 将有序数组转换为二叉搜索树

Convert Sorted Array to Binary Search Tree · Easy · 分治

## 题意

把严格升序数组转换成高度平衡的二叉搜索树，任意合法的平衡树都可接受。

## 约束要点

- 1 <= nums.length <= 104
- -104 <= nums[i] <= 104

## 示例输入

示例1

