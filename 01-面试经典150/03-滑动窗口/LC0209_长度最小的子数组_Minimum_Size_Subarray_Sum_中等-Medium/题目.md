# LC209 长度最小的子数组

Minimum Size Subarray Sum · Medium · 滑动窗口

## 题意

数组元素均为正整数，求和至少为target的最短连续子数组长度；不存在返回0。

## 约束要点

- 1 <= target <= 109
- 1 <= nums.length <= 105
- 1 <= nums[i] <= 104
