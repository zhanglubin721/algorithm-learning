# LC97 交错字符串

Interleaving String · Medium · 多维动态规划

## 题意

判断第三个字符串是否由前两个字符串交错组成；每个源字符串内部字符的相对顺序必须保持。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;
class Solution {
    public boolean isInterleave(String s1, String s2, String s3) { throw new UnsupportedOperationException("TODO"); }
}
```

输入依次为：s1（string）, s2（string）, s3（string）。

## 约束要点

- |n - m| <= 1
- 0 <= s1.length, s2.length <= 100
- 0 <= s3.length <= 200

## 示例输入

示例1

```text
"aabcc"
"dbbca"
"aadbbcbcac"
```

示例2

```text
"aabcc"
"dbbca"
"aadbbbaccc"
```

示例3

```text
""
""
""
```
