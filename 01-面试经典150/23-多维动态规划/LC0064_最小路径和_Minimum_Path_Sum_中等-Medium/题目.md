# LC64 最小路径和

Minimum Path Sum · Medium · 多维动态规划

## 题意

在非负权网格中只能向右或向下走，求从左上到右下经过的最小权值和。

- 1 <= m, n <= 200
- 0 <= grid[i][j] <= 200
