# LC322 零钱兑换

Coin Change · Medium · 一维动态规划

## 题意

每种硬币可无限使用，组成目标金额所需硬币数最少是多少？不能组成返回-1。

## 作答接口

```java
import java.util.*;

```

输入依次为：coins（integer[]）, amount（integer）。

## 约束要点

- 1 <= coins.length <= 12
- 1 <= coins[i] <= 231 - 1
- 0 <= amount <= 104

示例2
