# LC222 完全二叉树的节点个数

Count Complete Tree Nodes · Medium · 二叉树

## 题意

输入是完全二叉树，计算节点数量；进一步利用完全树性质减少遍历。

## 约束要点

- 树中节点的数目范围是[0, 5 * 104]
- 0 <= Node.val <= 5 * 104
- 题目数据保证输入的树是 完全二叉树
