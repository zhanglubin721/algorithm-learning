# LC100 相同的树

Same Tree · Easy · 二叉树

## 题意

判断两棵二叉树的结构和对应节点值是否完全一致。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;

class Solution {
    public boolean isSameTree(TreeNode p, TreeNode q) { throw new UnsupportedOperationException("TODO"); }
}
```

输入依次为：p（TreeNode）, q（TreeNode）。

## 约束要点

- 两棵树上的节点数目都在范围 [0, 100] 内

## 示例输入

示例1

```text
[1,2,3]
[1,2,3]
```

示例2

```text
[1,2]
[1,null,2]
```

示例3

```text
[1,2,1]
[1,1,2]
```
