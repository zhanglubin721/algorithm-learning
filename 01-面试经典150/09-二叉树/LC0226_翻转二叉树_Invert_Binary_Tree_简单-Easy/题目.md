# LC226 翻转二叉树

Invert Binary Tree · Easy · 二叉树

## 题意

交换二叉树每个节点的左右子树，返回翻转后的根。

## 约束要点

- 树中节点数目范围在 [0, 100] 内
- -100 <= Node.val <= 100
