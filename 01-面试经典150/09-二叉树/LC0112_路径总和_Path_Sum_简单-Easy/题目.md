# LC112 路径总和

Path Sum · Easy · 二叉树

## 题意

判断二叉树是否存在一条从根到叶子的路径，使节点值之和等于目标。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;

}
```

输入依次为：root（TreeNode）, targetSum（integer）。

## 约束要点

- 树中节点的数目在范围 [0, 5000] 内
- -1000 <= Node.val <= 1000
- -1000 <= targetSum <= 1000

## 示例输入

```text
[5,4,8,11,null,13,4,7,2,null,null,null,1]

```

