# LC290 单词规律

Word Pattern · Easy · 哈希表

## 题意

判断字符模式与空格分隔的单词序列是否构成双向一一对应。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;
class Solution {
    public boolean wordPattern(String pattern, String s) { throw new UnsupportedOperationException("TODO"); }
}
```

输入依次为：pattern（string）, s（string）。

## 约束要点

- pattern 中的每个字母都 恰好 映射到 s 中的一个唯一单词。
- s 中的每个唯一单词都 恰好 映射到 pattern 中的一个字母。
- 1 <= pattern.length <= 300
- pattern 只包含小写英文字母
- 1 <= s.length <= 3000
- s 只包含小写英文字母和 ' '

## 示例输入

示例1

```text
"abba"
"dog cat cat dog"
```

示例2

```text
"abba"
"dog cat cat fish"
```

示例3

```text
"aaaa"
"dog cat cat dog"
```
