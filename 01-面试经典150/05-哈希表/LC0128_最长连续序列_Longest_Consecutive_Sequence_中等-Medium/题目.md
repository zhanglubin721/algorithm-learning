# LC128 最长连续序列

Longest Consecutive Sequence · Medium · 哈希表

## 题意

找出整数集合中最长连续数值序列的长度；元素在原数组中不必相邻，要求O(n)量级算法。

## 约束要点

- 0 <= nums.length <= 105
- -109 <= nums[i] <= 109

## 示例输入

示例1

```text
[100,4,200,1,3,2]
```

示例2
