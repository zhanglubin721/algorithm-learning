# LC1 两数之和

Two Sum · Easy · 哈希表

## 题意

在整数数组中选出两个不同位置，使对应元素相加等于目标值，返回下标；题目保证存在唯一的下标对。

## 约束要点

- 2 <= nums.length <= 104
- -109 <= nums[i] <= 109
- -109 <= target <= 109
