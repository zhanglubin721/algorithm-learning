# LC219 存在重复元素 II

Contains Duplicate II · Easy · 哈希表

## 题意

判断是否存在两个值相同且下标距离不超过k的不同元素。

## 约束要点

- 1 <= nums.length <= 105
- -109 <= nums[i] <= 109
- 0 <= k <= 105

示例1

```text

```

示例2

