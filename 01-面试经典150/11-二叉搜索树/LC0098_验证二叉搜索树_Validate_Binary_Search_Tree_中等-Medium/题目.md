# LC98 验证二叉搜索树

Validate Binary Search Tree · Medium · 二叉搜索树

## 题意

判断二叉树是否为严格二叉搜索树：左子树所有值小于根，右子树所有值大于根。

}

## 约束要点

- 节点的左子树只包含 严格小于 当前节点的数。
- 节点的右子树只包含 严格大于 当前节点的数。
- 树中节点数目范围在[1, 104] 内
- -231 <= Node.val <= 231 - 1

## 示例输入

示例1

```text
[2,1,3]
```

示例2

```text
[5,1,4,null,null,3,6]
```
