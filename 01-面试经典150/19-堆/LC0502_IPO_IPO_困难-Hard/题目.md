# LC502 IPO

IPO · Hard · 堆

## 题意

最多完成k个项目，项目有启动资本要求和完成后的利润，求从初始资本出发能得到的最大资本。

## 约束要点

- 1 <= k <= 105
- 0 <= w <= 109
- 1 <= n <= 105
- 0 <= profits[i] <= 104
- 0 <= capital[i] <= 109
