# LC141 环形链表

Linked List Cycle · Easy · 链表

## 题意

判断单链表是否有环；输入中的pos仅用于构造环，不是提交方法的参数。

## 约束要点

- 链表中节点的数目范围是 [0, 104]
- -105 <= Node.val <= 105

```text

```

示例2
