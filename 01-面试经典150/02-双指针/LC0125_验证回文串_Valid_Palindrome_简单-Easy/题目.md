# LC125 验证回文串

Valid Palindrome · Easy · 双指针

## 题意

忽略非字母数字字符及大小写后，判断字符串是否为回文。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;

```

输入依次为：s（string）。

## 约束要点

- 1 <= s.length <= 2 * 105

## 示例输入

示例1

```text
"A man, a plan, a canal: Panama"
```

示例2

```text
"race a car"
```

```text

```
