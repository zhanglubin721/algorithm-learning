# LC380 O(1) 时间插入、删除和获取随机元素

Insert Delete GetRandom O(1) · Medium · 数组 / 字符串

## 题意

实现支持插入、删除和随机取值的集合，平均操作O(1)；getRandom应对当前元素均匀采样。

```java
}
```

## 约束要点

- int getRandom() 随机返回现有集合中的一项（测试用例保证调用此方法时集合中至少存在一个元素）。每个元素应该有 相同的概率 被返回。
- -231 <= val <= 231 - 1
