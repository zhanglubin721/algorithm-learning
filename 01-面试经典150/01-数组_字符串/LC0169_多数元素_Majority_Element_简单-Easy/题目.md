# LC169 多数元素

Majority Element · Easy · 数组 / 字符串

## 题意

返回数组中出现次数严格超过一半的元素，题目保证它存在。

## 约束要点

- 1 <= n <= 5 * 104
- -109 <= nums[i] <= 109
- 输入保证数组中一定有一个多数元素。

## 示例输入

示例1

```text
[3,2,3]
```

示例2

```text
[2,2,1,1,1,2,2]
```
