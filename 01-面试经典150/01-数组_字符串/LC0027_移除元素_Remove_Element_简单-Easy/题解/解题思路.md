### 方法一：一次遍历

> **思考**
>
> 题目要求原地移除所有等于 $val$ 的元素。若另开数组拷贝剩余元素，时间 $O(n)$， $n \le 100$ 可以接受，但多一次分配并不必要。
>
> 若每次删除都把后面的元素整体前移，最坏时间 $O(n^2)$。评测只要求前 $k$ 个位置覆盖全部非 $val$ 元素，相对顺序可以改变。
>
> 因此不必真正「删除」，把需要保留的值依次覆盖到数组前部即可。用 $k$ 记录已写下的个数，遇 $x \neq val$ 则写入 $nums[k]$ 并将 $k$ 加一。一遍扫描，额外空间 $O(1)$。

我们用变量 $k$ 记录当前不等于 $val$ 的元素个数。

遍历数组 $nums$，如果当前元素 $x$ 不等于 $val$，则将 $x$ 赋值给 $nums[k]$，并将 $k$ 自增 $1$。

最后返回 $k$ 即可。

时间复杂度 $O(n)$，空间复杂度 $O(1)$。其中 $n$ 为数组 $nums$ 的长度。

#### Java

```java
class Solution {
    public int removeElement(int[] nums, int val) {
        int k = 0;
        for (int x : nums) {
            if (x != val) {
                nums[k++] = x;
            }
        }
        return k;
    }
}
```
