# LC88 合并两个有序数组

Merge Sorted Array · Easy · 数组 / 字符串

## 题意

两个非递减数组分别有m和n个有效元素，第一个数组尾部预留n个位置。把合并结果直接写回第一个数组。

## 约束要点

- 0 <= m, n <= 200
- 1 <= m + n <= 200
- -109 <= nums1[i], nums2[j] <= 109
