# LC134 加油站

Gas Station · Medium · 数组 / 字符串

## 题意

环形路线每站提供汽油，移动到下一站有油耗。判断从哪里出发能完整走一圈，无解返回-1。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;
class Solution {
    public int canCompleteCircuit(int[] gas, int[] cost) { throw new UnsupportedOperationException("TODO"); }
}
```

输入依次为：gas（integer[]）, cost（integer[]）。

## 约束要点

- 1 <= n <= 105
- 0 <= gas[i], cost[i] <= 104
- 输入保证答案唯一。

## 示例输入

示例1

```text
[1,2,3,4,5]
[3,4,5,1,2]
```

示例2

```text
[2,3,4]
[3,4,3]
```
