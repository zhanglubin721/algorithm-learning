### 方法一：贪心

> **思考**
>
> 按千、百、十、个分别查表，再单独处理 $4$、 $9$ 的减法写法，在 $1 \le num \le 3999$ 的范围内可以接受，但普通累加与减法形式要分成两套规则，分支多、容易遗漏。
>
> 注意到，若把 $\textit{CM}=900$、 $\textit{CD}=400$、 $\textit{XC}=90$ 等也视为独立面额，罗马数字就变成一组从大到小的固定面值。题目保证表示唯一，因此每次选取还能放下的最大面额一定合法。我们按面额从大到小扫描，当前剩余值不小于该面额时便减去并拼接对应符号。

我们可以先将所有可能的符号 $cs$ 和对应的数值 $vs$ 列出来，然后从大到小枚举每个数值 $vs[i]$，每次尽可能多地使用该数值对应的符号 $cs[i]$，直到数字 $num$ 变为 $0$。

时间复杂度为 $O(m)$，空间复杂度为 $O(m)$。其中 $m$ 为符号的个数。

#### Java

```java
class Solution {
    public String intToRoman(int num) {
        List<String> cs
            = List.of("M", "CM", "D", "CD", "C", "XC", "L", "XL", "X", "IX", "V", "IV", "I");
        List<Integer> vs = List.of(1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1);
        StringBuilder ans = new StringBuilder();
        for (int i = 0, n = cs.size(); i < n; ++i) {
            while (num >= vs.get(i)) {
                num -= vs.get(i);
                ans.append(cs.get(i));
            }
        }
        return ans.toString();
    }
}
```
