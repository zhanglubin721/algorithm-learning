# LC26 删除有序数组中的重复项

Remove Duplicates from Sorted Array · Easy · 数组 / 字符串

## 题意

在升序数组中原地移除重复值，使每种值只出现一次。返回有效长度，前缀存放结果，尾部内容不作要求。
