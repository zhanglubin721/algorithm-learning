# LC45 跳跃游戏 II

Jump Game II · Medium · 数组 / 字符串

## 题意

数组元素表示当前位置向右最多能跳多远。题目保证能到达末尾，求从首元素到末元素的最少跳跃次数。

## 作答接口

```java

import java.util.stream.*;

```

输入依次为：nums（integer[]）。

## 约束要点

- 0 <= j <= nums[i] 且
- 1 <= nums.length <= 104
- 0 <= nums[i] <= 1000
- 题目保证可以到达 n - 1

## 示例输入

示例1

```text
[2,3,1,1,4]
```

示例2

```text
[2,3,0,1,4]
```
