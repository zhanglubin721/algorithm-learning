# LC135 分发糖果

Candy · Hard · 数组 / 字符串

## 题意

每个孩子至少一颗糖，评分较高的孩子必须比其相邻的低评分孩子获得更多糖，求最小总糖数。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;
class Solution {
    public int candy(int[] ratings) { throw new UnsupportedOperationException("TODO"); }
}
```

输入依次为：ratings（integer[]）。

## 约束要点

- 1 <= n == ratings.length <= 5 * 104
- 0 <= ratings[i] <= 5 * 104

## 示例输入

示例1

```text
[1,0,2]
```

示例2

```text
[1,2,2]
```
