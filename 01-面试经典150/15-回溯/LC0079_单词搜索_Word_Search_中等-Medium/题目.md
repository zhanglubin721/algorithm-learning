# LC79 单词搜索

Word Search · Medium · 回溯

## 题意

单词能否通过网格中上下左右相邻格子依次拼出？同一次搜索中每个格子最多使用一次。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;
class Solution {
    public boolean exist(char[][] board, String word) { throw new UnsupportedOperationException("TODO"); }
}
```

输入依次为：board（character[][]）, word（string）。

## 约束要点

- 1 <= m, n <= 6
- 1 <= word.length <= 15

## 示例输入

示例1

```text
[["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]]
"ABCCED"
```

示例2

```text
[["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]]
"SEE"
```

示例3

```text
[["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]]
"ABCB"
```
