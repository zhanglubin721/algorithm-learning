# LC210 课程表 II

Course Schedule II · Medium · 图

## 题意

根据先修依赖返回一种合法课程顺序，有环无法完成时返回空数组。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;

    public int[] findOrder(int numCourses, int[][] prerequisites) { throw new UnsupportedOperationException("TODO"); }
```

输入依次为：numCourses（integer）, prerequisites（integer[][]）。

## 约束要点

- 1 <= numCourses <= 2000
- 0 <= prerequisites.length <= numCourses * (numCourses - 1)
- 0 <= ai, bi < numCourses
- 所有[ai, bi] 互不相同
