# LC207 课程表

Course Schedule · Medium · 图

## 题意

课程之间有先修依赖，判断是否可能完成全部课程。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) { throw new UnsupportedOperationException("TODO"); }
}
```

输入依次为：numCourses（integer）, prerequisites（integer[][]）。

## 约束要点

- 1 <= numCourses <= 2000
- 0 <= prerequisites.length <= 5000
- 0 <= ai, bi < numCourses
- prerequisites[i] 中的所有课程对 互不相同

## 示例输入

示例1

```text
2
[[1,0]]
```

示例2

```text
2
[[1,0],[0,1]]
```
