# LC74 搜索二维矩阵

Search a 2D Matrix · Medium · 二分查找

## 题意

矩阵每行有序，后一行首元素大于前一行末元素。判断目标是否存在，要求对数级查找。

## 约束要点

- 1 <= m, n <= 100
- -104 <= matrix[i][j], target <= 104

## 示例输入

示例1

```text
[[1,3,5,7],[10,11,16,20],[23,30,34,60]]

```
