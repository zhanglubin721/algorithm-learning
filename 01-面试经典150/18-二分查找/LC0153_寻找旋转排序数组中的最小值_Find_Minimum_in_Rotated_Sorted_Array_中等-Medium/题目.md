# LC153 寻找旋转排序数组中的最小值

Find Minimum in Rotated Sorted Array · Medium · 二分查找

## 题意

严格升序数组经过旋转，求最小值，目标时间O(log n)。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;

}
```

输入依次为：nums（integer[]）。

## 约束要点

- 1 <= n <= 5000
- -5000 <= nums[i] <= 5000
- nums 中的所有整数 互不相同
- nums 原来是一个升序排序的数组，并进行了 1 至 n 次旋转

## 示例输入

示例1

```text
[3,4,5,1,2]
```

示例2

```text
[4,5,6,7,0,1,2]
```

示例3

```text
[11,13,15,17]
```
