# LC4 寻找两个正序数组的中位数

Median of Two Sorted Arrays · Hard · 二分查找

## 题意

给出两个有序数组，求合并后整体的中位数。目标时间复杂度为O(log(m+n))。

## 约束要点

- 0 <= m <= 1000
- 0 <= n <= 1000
- 1 <= m + n <= 2000
- -106 <= nums1[i], nums2[i] <= 106

## 示例输入

示例1

```text
[1,3]
[2]
```

示例2

```text
[1,2]
[3,4]
```
