# LC35 搜索插入位置

Search Insert Position · Easy · 二分查找

## 题意

在升序且无重复的数组中查找目标。若不存在，返回插入后仍能保持升序的位置。

## 约束要点

- 1 <= nums.length <= 104
- -104 <= nums[i] <= 104
- nums 为 无重复元素 的 升序 排列数组
- -104 <= target <= 104
