# LC137 只出现一次的数字 II

Single Number II · Medium · 位运算

## 题意

除一个整数仅出现一次外，其他数都出现三次，返回唯一的数。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;

```

输入依次为：nums（integer[]）。

## 约束要点

- 1 <= nums.length <= 3 * 104
- -231 <= nums[i] <= 231 - 1

## 示例输入

示例1

```text
[2,2,3,2]
```

示例2

```text
[0,1,0,1,0,1,99]
```
