# LC228 汇总区间

Summary Ranges · Easy · 区间

## 题意

把无重复的升序整数数组压缩成最短的连续区间字符串列表。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;
class Solution {
    public List<String> summaryRanges(int[] nums) { throw new UnsupportedOperationException("TODO"); }
}
```

输入依次为：nums（integer[]）。

## 约束要点

- 0 <= nums.length <= 20
- -231 <= nums[i] <= 231 - 1
- nums 中的所有值都 互不相同
- nums 按升序排列

## 示例输入

示例1

```text
[0,1,2,4,5,7]
```

示例2

```text
[0,2,3,4,6,8,9]
```
