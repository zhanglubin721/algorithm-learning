# LC57 插入区间

Insert Interval · Medium · 区间

## 题意

已有区间按起点升序排列且互不重叠。加入一个新区间并合并所有重叠区间，结果仍按顺序排列。

## 约束要点

- 0 <= intervals.length <= 104
- 0 <= starti <= endi <= 105
- intervals 根据 starti 按 升序 排列
- 0 <= start <= end <= 105

## 示例输入

示例1

```text
[[1,3],[6,9]]
[2,5]
```

示例2

```text
[[1,2],[3,5],[6,7],[8,10],[12,16]]
[4,8]
```
