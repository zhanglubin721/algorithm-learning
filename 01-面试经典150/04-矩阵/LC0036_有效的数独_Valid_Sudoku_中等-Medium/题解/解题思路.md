### 方法一：一次遍历

> **思考**
>
> 对每个已填数字再扫描它所在的行、列与宫，棋盘仅为 $9 \times 9$，时间可以接受。同一行、列、宫却会被反复访问。
>
> 判定有效性只需知道「这一行 / 列 / 宫是否已经出现过数字 $v$」。我们可以用三张布尔表 $row[i][v]$、 $col[j][v]$、 $sub[k][v]$ 在一次遍历中记录，其中宫号 $k = \lfloor i/3 \rfloor \times 3 + \lfloor j/3 \rfloor$。若碰到已经出现过的数字，立即返回假。

有效的数独满足以下三个条件：

- 每一行中的数字都不重复；
- 每一列中的数字都不重复；
- 每一个 $3 \times 3$ 的宫格中的数字都不重复。

遍历数独，对于每个数字，判断其所在的行、列 以及 $3 \times 3$ 的宫格是否已经出现过该数字，如果是，则返回 `false`。遍历结束，返回 `true`。

时间复杂度 $O(C)$，空间复杂度 $O(C)$，其中 $C$ 是数独中的空格数。本题中 $C=81$。

#### Java

```java
class Solution {
    public boolean isValidSudoku(char[][] board) {
        boolean[][] row = new boolean[9][9];
        boolean[][] col = new boolean[9][9];
        boolean[][] sub = new boolean[9][9];
        for (int i = 0; i < 9; ++i) {
            for (int j = 0; j < 9; ++j) {
                char c = board[i][j];
                if (c == '.') {
                    continue;
                }
                int num = c - '0' - 1;
                int k = i / 3 * 3 + j / 3;
                if (row[i][num] || col[j][num] || sub[k][num]) {
                    return false;
                }
                row[i][num] = true;
                col[j][num] = true;
                sub[k][num] = true;
            }
        }
        return true;
    }
}
```
