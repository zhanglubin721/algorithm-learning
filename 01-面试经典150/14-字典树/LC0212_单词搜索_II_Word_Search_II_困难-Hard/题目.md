# LC212 单词搜索 II

Word Search II · Hard · 字典树

## 题意

在小写字母网格中查找词表中的所有单词，上下左右移动，单条路径中格子不能重复使用。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;
class Solution {
    public List<String> findWords(char[][] board, String[] words) { throw new UnsupportedOperationException("TODO"); }
}
```

输入依次为：board（character[][]）, words（string[]）。

## 约束要点

- 1 <= m, n <= 12
- 1 <= words.length <= 3 * 104
- 1 <= words[i].length <= 10
- words 中的所有字符串互不相同

## 示例输入

示例1

```text
[["o","a","a","n"],["e","t","a","e"],["i","h","k","r"],["i","f","l","v"]]
["oath","pea","eat","rain"]
```

示例2

```text
[["a","b"],["c","d"]]
["abcb"]
```
