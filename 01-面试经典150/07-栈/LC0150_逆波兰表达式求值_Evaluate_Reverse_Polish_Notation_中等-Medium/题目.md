# LC150 逆波兰表达式求值

Evaluate Reverse Polish Notation · Medium · 栈

## 题意

计算逆波兰表达式；整数除法向零截断。

```java
import java.util.*;

```

## 约束要点

- 1 <= tokens.length <= 104
- tokens[i] 是一个算符（"+"、"-"、"*" 或 "/"），或是在范围 [-200, 200] 内的一个整数

## 示例输入

示例1

```text
["2","1","+","3","*"]
```

示例2

```text
["4","13","5","/","+"]
```

示例3

```text
["10","6","9","3","+","-11","*","/","*","17","+","5","+"]
```
