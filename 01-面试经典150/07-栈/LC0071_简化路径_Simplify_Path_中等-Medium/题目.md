# LC71 简化路径

Simplify Path · Medium · 栈

## 题意

规范化Unix绝对路径：处理多余斜线、当前目录和上级目录，保留普通目录名。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;
class Solution {
    public String simplifyPath(String path) { throw new UnsupportedOperationException("TODO"); }
}
```

输入依次为：path（string）。

## 约束要点

- 1 <= path.length <= 3000

## 示例输入

示例1

```text
"/home/"
```

示例2

```text
"/home//foo/"
```

示例3

```text
"/home/user/Documents/../Pictures"
```

示例4

```text
"/../"
```

示例5

```text
"/.../a/../b/c/../d/./"
```
