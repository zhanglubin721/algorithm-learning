# LC149 直线上最多的点数

Max Points on a Line · Hard · 数学

## 题意

在二维平面不同点中，求最多有多少点共线。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;
```

## 约束要点

- points 中的所有点 互不相同

## 示例输入

示例1

```text
[[1,1],[2,2],[3,3]]
```

示例2

```text
[[1,1],[3,2],[5,3],[4,1],[2,3],[1,4]]
```
