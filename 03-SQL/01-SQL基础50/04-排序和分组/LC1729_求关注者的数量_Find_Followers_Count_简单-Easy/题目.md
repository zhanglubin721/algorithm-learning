# LC1729 求关注者的数量

Find Followers Count · Easy · 排序和分组

## 题意

统计每个用户的粉丝数量，按用户编号升序输出。

## 表结构

```sql
Create table If Not Exists Followers(user_id int, follower_id int);
```

结果需要按题意排序。

## 示例输入

示例1 · Followers

| user_id | follower_id |
| --- | --- |
| 0 | 1 |
| 1 | 0 |
| 2 | 0 |
| 2 | 1 |
