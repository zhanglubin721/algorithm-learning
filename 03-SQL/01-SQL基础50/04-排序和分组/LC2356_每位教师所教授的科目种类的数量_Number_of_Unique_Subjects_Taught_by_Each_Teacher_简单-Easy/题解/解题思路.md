### 方法一

> **思考**
>
> 每位教师讲授的不同课程数。同一教师可能在不同院系重复同一科目，须去重。
>
> 按 $teacher\_id$ 分组，对 $subject\_id$ 做 $COUNT(DISTINCT \cdot)$。

#### MySQL

```sql
# Write your MySQL query statement below
SELECT teacher_id, COUNT(DISTINCT subject_id) AS cnt
FROM Teacher
GROUP BY 1;
```
