# LC2356 每位教师所教授的科目种类的数量

Number of Unique Subjects Taught by Each Teacher · Easy · 排序和分组

## 题意

统计每位教师教授的不同课程数量；同一课程在多个部门出现只计一次。

## 表结构

```sql
Create table If Not Exists Teacher (teacher_id int, subject_id int, dept_id int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Teacher

| teacher_id | subject_id | dept_id |
| --- | --- | --- |
| 1 | 2 | 3 |
| 1 | 2 | 4 |
| 1 | 3 | 3 |
| 2 | 1 | 1 |
| 2 | 2 | 1 |
| 2 | 3 | 1 |
| 2 | 4 | 1 |
