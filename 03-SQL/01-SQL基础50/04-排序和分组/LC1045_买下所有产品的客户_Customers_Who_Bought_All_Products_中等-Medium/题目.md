# LC1045 买下所有产品的客户

Customers Who Bought All Products · Medium · 排序和分组

## 题意

找出购买过Product表中所有产品的客户；同一个产品的重复购买不能增加覆盖数量。

## 表结构

```sql
Create table If Not Exists Customer (customer_id int, product_key int);
Create table Product (product_key int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Customer

| customer_id | product_key |
| --- | --- |
| 1 | 5 |
| 2 | 6 |
| 3 | 5 |
| 3 | 6 |
| 1 | 6 |

示例1 · Product

| product_key |
| --- |
| 5 |
| 6 |
