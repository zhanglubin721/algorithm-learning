# LC619 只出现一次的最大数字

Biggest Single Number · Easy · 排序和分组

## 题意

在只出现过一次的数中返回最大值；不存在这样的数时返回一行NULL。

## 表结构

```sql
Create table If Not Exists MyNumbers (num int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · MyNumbers

| num |
| --- |
| 8 |
| 8 |
| 3 |
| 3 |
| 1 |
| 4 |
| 5 |
| 6 |

示例2 · MyNumbers

| num |
| --- |
| 8 |
| 8 |
| 7 |
| 7 |
| 3 |
| 3 |
| 3 |
