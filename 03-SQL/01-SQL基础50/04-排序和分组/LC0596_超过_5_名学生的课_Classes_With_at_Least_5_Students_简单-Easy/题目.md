# LC596 超过 5 名学生的课

Classes With at Least 5 Students · Easy · 排序和分组

## 题意

找出至少有5名学生选修的课程。

## 表结构

```sql
Create table If Not Exists Courses (student varchar(255), class varchar(255));
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Courses

| student | class |

| A | Math |
| B | English |
| C | Math |
| D | Biology |
| E | Math |
| F | Computer |
| G | Math |
