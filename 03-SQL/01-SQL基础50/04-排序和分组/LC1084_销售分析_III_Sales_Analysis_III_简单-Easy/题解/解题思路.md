### 方法一：JOIN + GROUP BY + HAVING

> **思考**
>
> 只要在 $2019$ 年第一季度售出、且该季度之外没有销售的产品。按产品看全部销售日期是否都落在窗口内。
>
> 连接名称后分组，若行数等于「日期落在 $[2019\text{-}01\text{-}01,2019\text{-}03\text{-}31]$」的行数，则全部销售都在该季度。
>
> `COUNT(1) = SUM(sale_date BETWEEN ...)` 同时排除无销售与窗口外销售。

我们可以通过 `JOIN` 将 `Sales` 表和 `Product` 表连接起来，然后通过 `GROUP BY` 和 `HAVING` 来筛选出符合条件的产品。

#### MySQL

```sql
# Write your MySQL query statement below
SELECT product_id, product_name
FROM
    Sales
    JOIN Product USING (product_id)
GROUP BY 1
HAVING COUNT(1) = SUM(sale_date BETWEEN '2019-01-01' AND '2019-03-31');
```
