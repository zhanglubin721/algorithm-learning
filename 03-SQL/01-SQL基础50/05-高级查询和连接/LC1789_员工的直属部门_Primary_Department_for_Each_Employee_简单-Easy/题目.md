# LC1789 员工的直属部门

Primary Department for Each Employee · Easy · 高级查询和连接

## 题意

有多个部门的员工选择标记为主部门的记录；只有一个部门的员工直接返回其唯一部门。

## 表结构

```sql
Create table If Not Exists Employee (employee_id int, department_id int, primary_flag ENUM('Y','N'));
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Employee

| employee_id | department_id | primary_flag |
| --- | --- | --- |
| 1 | 1 | N |
| 2 | 1 | Y |
| 2 | 2 | N |
| 3 | 3 | N |
| 4 | 2 | N |
| 4 | 3 | Y |
| 4 | 4 | N |
