# LC1731 每位经理的下属员工数量

The Number of Employees Which Report to Each Employee · Easy · 高级查询和连接

## 题意

对有直接下属的员工输出编号、姓名、下属数和下属平均年龄，平均年龄取整，按员工编号排序。

## 表结构

```sql
Create table If Not Exists Employees(employee_id int, name varchar(20), reports_to int, age int);
```

结果需要按题意排序。
