# LC1907 按分类统计薪水

Count Salary Categories · Medium · 高级查询和连接

## 题意

按收入低于20000、介于20000和50000之间（含端点）、高于50000分成三类，三类即使人数为0也要输出。

## 表结构

```sql
Create table If Not Exists Accounts (account_id int, income int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Accounts

| account_id | income |
| --- | --- |
| 3 | 108939 |
| 2 | 12747 |
| 8 | 87709 |
| 6 | 91796 |
