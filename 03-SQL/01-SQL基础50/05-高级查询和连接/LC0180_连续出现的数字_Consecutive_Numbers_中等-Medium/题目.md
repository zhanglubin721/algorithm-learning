# LC180 连续出现的数字

Consecutive Numbers · Medium · 高级查询和连接

## 题意

找出在Logs中连续至少出现3次的数字，结果去重。

## 表结构

```sql
Create table If Not Exists Logs (id int, num int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Logs

| id | num |
| --- | --- |
| 1 | 1 |
| 2 | 1 |
| 3 | 1 |
| 4 | 2 |
| 5 | 1 |
| 6 | 2 |
| 7 | 2 |
