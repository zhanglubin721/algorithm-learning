### 方法一

> **思考**
>
> 上车顺序由 $turn$ 唯一确定，能否上车只取决于到该人为止的体重前缀和是否不超过 $1000$。自连接把每个人与所有不晚于他的人配对，按人聚合后用 $HAVING$ 筛出仍能上车的人，再取 $turn$ 最大者即为最后上车的人。

#### MySQL

```sql
# Write your MySQL query statement below
SELECT a.person_name
FROM
    Queue AS a,
    Queue AS b
WHERE a.turn >= b.turn
GROUP BY a.person_id
HAVING SUM(b.weight) <= 1000
ORDER BY a.turn DESC
LIMIT 1;
```
