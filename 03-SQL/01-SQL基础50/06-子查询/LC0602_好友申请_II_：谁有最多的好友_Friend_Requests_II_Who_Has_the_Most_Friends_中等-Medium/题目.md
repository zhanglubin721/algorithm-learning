# LC602 好友申请 II ：谁有最多的好友

Friend Requests II: Who Has the Most Friends · Medium · 子查询

## 题意

好友关系为双向，计算好友最多的人的编号及好友数；题目约束保证最多者唯一。

## 表结构

```sql
Create table If Not Exists RequestAccepted (requester_id int not null, accepter_id int null, accept_date date null);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · RequestAccepted

| requester_id | accepter_id | accept_date |
| --- | --- | --- |
| 1 | 2 | 2016/06/03 |
| 1 | 3 | 2016/06/08 |
| 2 | 3 | 2016/06/08 |
| 3 | 4 | 2016/06/09 |
