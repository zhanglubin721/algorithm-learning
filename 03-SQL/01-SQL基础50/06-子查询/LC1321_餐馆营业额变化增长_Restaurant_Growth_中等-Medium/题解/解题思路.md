### 方法一

> **思考**
>
> 每个日期需要含当日在内往前 $7$ 天的金额总和与日均，且窗口必须满 $7$ 天。按天先聚合金额，再对日期排序做 $\mathrm{ROWS}\,6\,\mathrm{PRECEDING}$ 的窗口和，并用窗口名次丢掉前 $6$ 天，剩下的行即为合法的七日均值。

#### MySQL

```sql
# Write your MySQL query statement below
WITH
    t AS (
        SELECT
            visited_on,
            SUM(amount) OVER (
                ORDER BY visited_on
                ROWS 6 PRECEDING
            ) AS amount,
            RANK() OVER (ORDER BY visited_on) AS rk
        FROM
            (
                SELECT visited_on, SUM(amount) AS amount
                FROM Customer
                GROUP BY visited_on
            ) AS tt
    )
SELECT visited_on, amount, ROUND(amount / 7, 2) AS average_amount
FROM t
WHERE rk > 6
ORDER BY visited_on;
```
