# LC1321 餐馆营业额变化增长

Restaurant Growth · Medium · 子查询

## 题意

先按访问日期汇总营业额，再计算包含当天的连续7天累计金额与日均金额；从第7天开始输出，均值保留两位小数。

## 表结构

```sql
Create table If Not Exists Customer (customer_id int, name varchar(20), visited_on date, amount int);
```

结果需要按题意排序。
