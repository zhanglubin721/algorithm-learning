# LC626 换座位

Exchange Seats · Medium · 子查询

## 题意

按连续座位编号交换每对相邻学生，人数为奇数时最后一个学生不变，结果按座位编号排序。

## 表结构

```sql
Create table If Not Exists Seat (id int, student varchar(255));
```

结果需要按题意排序。

## 示例输入

示例1 · Seat

| id | student |
| --- | --- |
| 1 | Abbot |
| 2 | Doris |
| 3 | Emerson |
| 4 | Green |
| 5 | Jeames |
