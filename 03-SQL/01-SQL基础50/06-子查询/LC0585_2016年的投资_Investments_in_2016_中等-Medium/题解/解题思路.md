### 方法一

> **思考**
>
> 2016 年投保额要满足：2015 年投保额有人相同，且经纬度独一无二。对每行再扫全表是平方级。
>
> 窗口按 `tiv_2015` 计数、按 `(lat, lon)` 计数。留下 $cnt1>1$ 且 $cnt2=1$ 的行，对其 `tiv_2016` 求和并四舍五入。一次窗口扫描代替相关子查询。

#### MySQL

```sql
# Write your MySQL query statement below
WITH
    T AS (
        SELECT
            tiv_2016,
            COUNT(1) OVER (PARTITION BY tiv_2015) AS cnt1,
            COUNT(1) OVER (PARTITION BY lat, lon) AS cnt2
        FROM Insurance
    )
SELECT ROUND(SUM(tiv_2016), 2) AS tiv_2016
FROM T
WHERE cnt1 > 1 AND cnt2 = 1;
```
