# LC1978 上级经理已离职的公司员工

Employees Whose Manager Left the Company · Easy · 子查询

## 题意

找出工资低于30000且其非空经理编号已不存在于员工表中的员工，按编号升序输出。

## 表结构

```sql
Create table If Not Exists Employees (employee_id int, name varchar(20), manager_id int, salary int);
```

结果需要按题意排序。

## 示例输入
