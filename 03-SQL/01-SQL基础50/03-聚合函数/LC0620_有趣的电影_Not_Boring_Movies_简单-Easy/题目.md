# LC620 有趣的电影

Not Boring Movies · Easy · 聚合函数

## 题意

筛选编号为奇数且描述不是boring的电影，按评分从高到低输出。

## 表结构

```sql
Create table If Not Exists cinema (id int, movie varchar(255), description varchar(255), rating float(2, 1));
```

结果需要按题意排序。

## 示例输入

示例1 · cinema

| id | movie | description | rating |
| --- | --- | --- | --- |
| 1 | War | great 3D | 8.9 |
| 2 | Science | fiction | 8.5 |
| 3 | irish | boring | 6.2 |
| 4 | Ice song | Fantacy | 8.6 |
| 5 | House card | Interesting | 9.1 |

## 本地使用

运行入口中的Start.java，在控制台选择新一轮，然后编辑作答目录生成的副本。树用层序数组表示，链表用值数组表示；设计题使用操作名数组和参数数组。
