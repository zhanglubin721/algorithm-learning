# LC550 游戏玩法分析 IV

Game Play Analysis IV · Medium · 聚合函数

## 题意

计算所有玩家中，在首次登录后的下一自然日也登录过的玩家比例，保留两位小数。

## 表结构

```sql
Create table If Not Exists Activity (player_id int, device_id int, event_date date, games_played int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Activity

| player_id | device_id | event_date | games_played |
| --- | --- | --- | --- |
| 1 | 2 | 2016-03-01 | 5 |
| 1 | 2 | 2016-03-02 | 6 |
| 2 | 3 | 2017-06-25 | 1 |
| 3 | 1 | 2016-03-02 | 0 |
| 3 | 4 | 2018-07-03 | 5 |
