# LC1211 查询结果的质量和占比

Queries Quality and Percentage · Easy · 聚合函数

## 题意

按查询名称计算平均rating/position作为质量，以及rating小于3的记录百分比，两项都保留两位小数。

## 表结构

```sql
Create table If Not Exists Queries (query_name varchar(30), result varchar(50), position int, rating int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Queries

| query_name | result | position | rating |
| --- | --- | --- | --- |
| Dog | Golden Retriever | 1 | 5 |
| Dog | German Shepherd | 2 | 5 |
| Dog | Mule | 200 | 1 |
| Cat | Shirazi | 5 | 2 |
| Cat | Siamese | 3 | 3 |
| Cat | Sphynx | 7 | 4 |
