# LC1527 患某种疾病的患者

Patients With a Condition · Easy · 高级字符串函数 / 正则表达式 / 子句

## 题意

找出conditions中包含以DIAB1开头的独立疾病编码的患者；DIAB1前必须是字符串开头或空格。

## 表结构

```sql
Create table If Not Exists Patients (patient_id int, patient_name varchar(30), conditions varchar(100));
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Patients

| patient_id | patient_name | conditions |
| --- | --- | --- |
| 1 | Daniel | YFEV COUGH |
| 2 | Alice |  |
| 3 | Bob | DIAB100 MYOP |
| 4 | George | ACNE DIAB100 |
