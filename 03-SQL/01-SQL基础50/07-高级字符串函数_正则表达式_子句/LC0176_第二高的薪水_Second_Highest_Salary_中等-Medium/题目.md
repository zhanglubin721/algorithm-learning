# LC176 第二高的薪水

Second Highest Salary · Medium · 高级字符串函数 / 正则表达式 / 子句

## 题意

返回第二高的不同薪水，不存在时返回一行NULL。

## 表结构

```sql
Create table If Not Exists Employee (id int, salary int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Employee

| id | salary |
| --- | --- |
| 1 | 100 |
| 2 | 200 |
| 3 | 300 |

示例2 · Employee

| id | salary |
| --- | --- |
| 1 | 100 |
