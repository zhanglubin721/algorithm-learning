# LC196 删除重复的电子邮箱

Delete Duplicate Emails · Easy · 高级字符串函数 / 正则表达式 / 子句

## 题意

删除重复电子邮箱记录，每种邮箱仅保留最小id对应的一行；本题要求执行DELETE。

## 表结构

```sql
Create table If Not Exists Person (Id int, Email varchar(255));
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Person

| id | email |
| --- | --- |
| 1 | john@example.com |
| 2 | bob@example.com |
| 3 | john@example.com |
