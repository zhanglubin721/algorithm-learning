# LC1517 查找拥有有效邮箱的用户

Find Users With Valid E-Mails · Easy · 高级字符串函数 / 正则表达式 / 子句

## 题意

邮箱前缀必须以字母开头，其余仅允许字母、数字、下划线、点和连字符；域名必须准确为leetcode.com。

## 表结构

```sql
Create table If Not Exists Users (user_id int, name varchar(30), mail varchar(50));
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。
