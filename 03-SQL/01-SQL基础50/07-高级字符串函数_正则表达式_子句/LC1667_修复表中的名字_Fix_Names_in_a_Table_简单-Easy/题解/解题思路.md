### 方法一

> **思考**
>
> 姓名需首字母大写、其余小写。用 $\texttt{UPPER}(\texttt{LEFT}(name,1))$ 与 $\texttt{LOWER}(\texttt{SUBSTRING}(name,2))$ 拼接，再按 $\texttt{user\_id}$ 排序。

#### MySQL

```sql
SELECT
    user_id,
    CONCAT(UPPER(LEFT(name, 1)), LOWER(SUBSTRING(name, 2))) AS name
FROM
    users
ORDER BY
    user_id;
```
