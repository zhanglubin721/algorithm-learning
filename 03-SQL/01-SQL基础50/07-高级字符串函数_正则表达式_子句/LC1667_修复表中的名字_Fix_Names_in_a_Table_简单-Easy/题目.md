# LC1667 修复表中的名字

Fix Names in a Table · Easy · 高级字符串函数 / 正则表达式 / 子句

## 题意

规范化用户姓名：首字符大写，其余字符小写，按用户编号升序输出。

## 表结构

```sql
Create table If Not Exists Users (user_id int, name varchar(40));
```

结果需要按题意排序。

## 示例输入

示例1 · Users

| user_id | name |
| --- | --- |
| 1 | aLice |
| 2 | bOB |
