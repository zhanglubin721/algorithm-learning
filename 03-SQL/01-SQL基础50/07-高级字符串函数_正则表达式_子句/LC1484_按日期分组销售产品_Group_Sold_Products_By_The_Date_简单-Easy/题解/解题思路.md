### 方法一

> **思考**
>
> 按销售日期统计去重后的商品种数，并把名称按字典序拼成串。`GROUP BY sell_date` 后用 `COUNT(DISTINCT product)` 与 `GROUP_CONCAT(DISTINCT product)` 即可。

#### MySQL

```sql
SELECT
    sell_date,
    COUNT(DISTINCT product) AS num_sold,
    GROUP_CONCAT(DISTINCT product) AS products
FROM Activities
GROUP BY sell_date
ORDER BY sell_date;
```
