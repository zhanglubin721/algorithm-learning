# LC1484 按日期分组销售产品

Group Sold Products By The Date · Easy · 高级字符串函数 / 正则表达式 / 子句

## 题意

按销售日期汇总不同商品数量，并把不同商品名称按字典序用逗号连接；按日期排序。

## 表结构

```sql
Create table If Not Exists Activities (sell_date date, product varchar(20));
```

结果需要按题意排序。

## 示例输入

示例1 · Activities

| sell_date | product |
| --- | --- |
| 2020-05-30 | Headphone |
| 2020-06-01 | Pencil |
| 2020-06-02 | Mask |
| 2020-05-30 | Basketball |
| 2020-06-01 | Bible |
| 2020-06-02 | Mask |
| 2020-05-30 | T-Shirt |
