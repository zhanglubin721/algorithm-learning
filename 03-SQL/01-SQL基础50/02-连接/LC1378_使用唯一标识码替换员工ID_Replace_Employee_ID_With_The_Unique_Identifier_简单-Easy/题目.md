# LC1378 使用唯一标识码替换员工ID

Replace Employee ID With The Unique Identifier · Easy · 连接

## 题意

为每个员工补充唯一标识，没有对应唯一标识的员工也要保留并显示NULL。

## 表结构

```sql
Create table If Not Exists Employees (id int, name varchar(20));
Create table If Not Exists EmployeeUNI (id int, unique_id int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Employees

| id | name |
| --- | --- |
| 1 | Alice |
| 7 | Bob |
| 11 | Meir |
| 90 | Winston |
| 3 | Jonathan |

示例1 · EmployeeUNI

| id | unique_id |
| --- | --- |
| 3 | 1 |
| 11 | 2 |
| 90 | 3 |
