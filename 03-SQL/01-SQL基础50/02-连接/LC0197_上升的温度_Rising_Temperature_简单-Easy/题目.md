# LC197 上升的温度

Rising Temperature · Easy · 连接

## 题意

找出温度高于前一个自然日的天气记录编号；缺少前一天记录时不能作比较。

## 表结构

```sql
Create table If Not Exists Weather (id int, recordDate date, temperature int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Weather

| id | recordDate | temperature |
| --- | --- | --- |
| 1 | 2015-01-01 | 10 |
| 2 | 2015-01-02 | 25 |
| 3 | 2015-01-03 | 20 |
| 4 | 2015-01-04 | 30 |
