### 方法一：分组统计 + 连接

> **思考**
>
> 经理是「至少五名直接下属」的员工。先按 `managerId` 计数，再连回员工表取姓名。
>
> 分组统计每个经理的下属人数，过滤 $\ge 5$，再与 `Employee` 按 id 连接。聚合与连接分工明确，避免在原表上重复扫描下属。

我们可以先统计每个经理的直接下属人数，然后再连接 `Employee` 表，找出直接下属人数大于等于 $5$ 的经理。

#### MySQL

```sql
# Write your MySQL query statement below
SELECT name
FROM
    Employee
    JOIN (
        SELECT managerId AS id, COUNT(1) AS cnt
        FROM Employee
        GROUP BY 1
        HAVING cnt >= 5
    ) AS t
        USING (id);
```
