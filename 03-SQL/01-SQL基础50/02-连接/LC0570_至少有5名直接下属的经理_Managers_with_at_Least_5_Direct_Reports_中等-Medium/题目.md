# LC570 至少有5名直接下属的经理

Managers with at Least 5 Direct Reports · Medium · 连接

## 题意

找出至少有5名直接下属的经理姓名，只统计直接汇报关系。

## 表结构

```sql
Create table If Not Exists Employee (id int, name varchar(255), department varchar(255), managerId int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Employee

| id | name | department | managerId |
| --- | --- | --- | --- |
| 101 | John | A | NULL |
| 102 | Dan | A | 101 |
| 103 | James | A | 101 |
| 104 | Amy | A | 101 |
| 105 | Anne | A | 101 |
| 106 | Ron | B | 101 |
