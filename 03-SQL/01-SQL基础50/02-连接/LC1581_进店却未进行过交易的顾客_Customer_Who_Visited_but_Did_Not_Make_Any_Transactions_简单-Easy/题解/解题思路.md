### 方法一：子查询 + 分组统计

> **思考**
>
> 统计每位顾客「到访但未消费」的次数。消费记录在另一张表，需要找出没有对应交易的访问。
>
> 子查询列出所有出现在 $Transactions$ 中的 $visit\_id$，外层保留不在该集合中的访问，再按顾客计数。

我们可以使用子查询，先找出所有没有进行交易的 `visit_id`，然后按照 `customer_id` 进行分组，统计每个顾客的没有进行交易的次数。

#### MySQL

```sql
# Write your MySQL query statement below
SELECT customer_id, COUNT(1) AS count_no_trans
FROM Visits
WHERE visit_id NOT IN (SELECT visit_id FROM Transactions)
GROUP BY 1;
```
