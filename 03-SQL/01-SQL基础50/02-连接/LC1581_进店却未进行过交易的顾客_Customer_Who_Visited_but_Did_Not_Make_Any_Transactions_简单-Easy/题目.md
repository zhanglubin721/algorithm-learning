# LC1581 进店却未进行过交易的顾客

Customer Who Visited but Did Not Make Any Transactions · Easy · 连接

## 题意

按客户统计没有发生任何交易的访问次数，仅输出有此类访问的客户。

## 表结构

```sql
Create table If Not Exists Visits(visit_id int, customer_id int);
Create table If Not Exists Transactions(transaction_id int, visit_id int, amount int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Visits

| visit_id | customer_id |
| --- | --- |
| 1 | 23 |
| 2 | 9 |
| 4 | 30 |
| 5 | 54 |

| 7 | 54 |
