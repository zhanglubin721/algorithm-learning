# LC584 寻找用户推荐人

Find Customer Referee · Easy · 查询

## 题意

返回推荐人不是编号2的客户姓名；没有推荐人的客户也要保留。

## 表结构

```sql
Create table If Not Exists Customer (id int, name varchar(25), referee_id int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Customer

| id | name | referee_id |
| --- | --- | --- |
| 1 | Will | NULL |
| 2 | Jane | NULL |
| 3 | Alex | 2 |
| 4 | Bill | NULL |
| 5 | Zack | 1 |
| 6 | Mark | 2 |
