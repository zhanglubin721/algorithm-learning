# LC595 大的国家

Big Countries · Easy · 查询

## 题意

筛选面积至少300万或人口至少2500万的国家，输出国家名、人口和面积。

## 表结构

```sql
Create table If Not Exists World (name varchar(255), continent varchar(255), area int, population int, gdp bigint);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。
