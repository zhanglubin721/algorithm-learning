# LC1757 可回收且低脂的产品

Recyclable and Low Fat Products · Easy · 查询

## 题意

从Products中找出同时满足低脂和可回收两个条件的产品编号。

## 表结构

```sql
Create table If Not Exists Products (product_id int, low_fats ENUM('Y', 'N'), recyclable ENUM('Y','N'));
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Products

| product_id | low_fats | recyclable |
| --- | --- | --- |
| 0 | Y | N |
| 1 | Y | Y |
| 2 | N | Y |
| 3 | Y | Y |
| 4 | N | N |
