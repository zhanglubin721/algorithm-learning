# LC1683 无效的推文

Invalid Tweets · Easy · 查询

## 题意

找出内容字符数严格大于15的推文编号。

## 表结构

```sql
Create table If Not Exists Tweets(tweet_id int, content varchar(50));
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Tweets

| tweet_id | content |
| --- | --- |
| 1 | Let us Code |
| 2 | More than fifteen chars are here! |
