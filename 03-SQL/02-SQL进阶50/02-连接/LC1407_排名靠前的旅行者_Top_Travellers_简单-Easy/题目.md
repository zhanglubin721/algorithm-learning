# LC1407 排名靠前的旅行者

Top Travellers · Easy · 连接

## 题意

统计每个用户旅行总距离，没有出行记录记0；按距离降序、姓名升序输出。

## 表结构

```sql
Create Table If Not Exists Users (id int, name varchar(30));
Create Table If Not Exists Rides (id int, user_id int, distance int);
```

结果需要按题意排序。
