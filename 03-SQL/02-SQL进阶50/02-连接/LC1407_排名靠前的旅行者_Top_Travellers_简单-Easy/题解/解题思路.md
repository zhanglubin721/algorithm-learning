### 方法一：左连接 + 分组统计

> **思考**
>
> 需要输出每一位用户的累计里程，包括从未乘车的用户。内连接会丢掉无行程的用户，因此以 `Users` 为左表连接 `Rides`。
>
> 按用户 `id` 分组后对 `distance` 求和，无行程时 `SUM` 为 `NULL`，用 `IFNULL` 转为 $0$。再按里程降序、姓名升序排序。

我们可以使用左连接，将 `Users` 表与 `Rides` 表按照用户 id 连接，然后按照用户 id 分组，统计每个用户的旅行距离。注意，如果用户没有旅行记录，那么旅行距离为 $0$。

#### MySQL

```sql
# Write your MySQL query statement below
SELECT name, IFNULL(SUM(distance), 0) AS travelled_distance
FROM
    Users AS u
    LEFT JOIN Rides AS r ON u.id = r.user_id
GROUP BY u.id
ORDER BY 2 DESC, 1;
```
