# LC1440 计算布尔表达式的值

Evaluate Boolean Expression · Medium · 连接

## 题意

根据Variables里的变量值计算每条Expressions比较表达式，追加字符串true或false作为结果。

## 表结构

```sql
Create Table If Not Exists Variables (name varchar(3), value int);
Create Table If Not Exists Expressions (left_operand varchar(3), operator ENUM('>', '<', '='), right_operand varchar(3));
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Variables

| name | value |
| --- | --- |
| x | 66 |
| y | 77 |

示例1 · Expressions

| left_operand | operator | right_operand |
| --- | --- | --- |
| x | > | y |
| x | < | y |
| x | = | y |
| y | > | x |
| y | < | x |
| x | = | x |
