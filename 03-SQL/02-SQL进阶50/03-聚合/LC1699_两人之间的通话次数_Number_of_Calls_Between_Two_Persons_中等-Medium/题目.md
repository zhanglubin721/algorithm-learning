# LC1699 两人之间的通话次数

Number of Calls Between Two Persons · Medium · 聚合

## 题意

通话双方不分方向，以较小编号在前的方式归并，统计每对用户的通话次数和总时长。

## 表结构

```sql
Create table If Not Exists Calls (from_id int, to_id int, duration int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Calls

| from_id | to_id | duration |
| --- | --- | --- |
| 1 | 2 | 59 |
| 2 | 1 | 11 |
| 1 | 3 | 20 |
| 3 | 4 | 100 |
| 3 | 4 | 200 |
| 3 | 4 | 200 |
| 4 | 3 | 499 |
