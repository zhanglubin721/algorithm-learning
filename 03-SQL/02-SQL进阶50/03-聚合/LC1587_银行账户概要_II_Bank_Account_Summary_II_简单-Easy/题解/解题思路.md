### 方法一：等值连接 + 分组求和

> **思考**
>
> 列出余额超过 $10000$ 的用户。姓名在用户表，流水在交易表，必须先按账户对齐再汇总。
>
> 等值连接后按账户对 $amount$ 求和，用 $HAVING$ 留下余额大于 $10000$ 的组，同时选出姓名。

我们可以使用等值连接，将 `Users` 和 `Transactions` 表按照 `account` 列连接起来，然后按照 `account` 列分组求和，最后筛选出余额大于 $10000$ 的用户。

#### MySQL

```sql
# Write your MySQL query statement below
SELECT
    name,
    SUM(amount) AS balance
FROM
    Users
    JOIN Transactions USING (account)
GROUP BY account
HAVING balance > 10000;
```
