# LC586 订单最多的客户

Customer Placing the Largest Number of Orders · Easy · 聚合

## 题意

返回订单数量最多的客户编号；题目保证该客户唯一。

## 表结构

```sql
Create table If Not Exists orders (order_number int, customer_number int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · orders

| order_number | customer_number |
| --- | --- |
| 1 | 1 |
| 2 | 2 |
| 3 | 3 |
| 4 | 3 |
