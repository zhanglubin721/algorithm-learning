# LC1741 查找每个员工花费的总时间

Find Total Time Spent by Each Employee · Easy · 聚合

## 题意

按员工和日期汇总全部out_time减in_time的工作时长。

## 表结构

```sql
Create table If Not Exists Employees(emp_id int, event_day date, in_time int, out_time int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Employees

| emp_id | event_day | in_time | out_time |
| --- | --- | --- | --- |
| 1 | 2020-11-28 | 4 | 32 |
| 1 | 2020-11-28 | 55 | 200 |
| 1 | 2020-12-3 | 1 | 42 |
| 2 | 2020-11-28 | 3 | 33 |
| 2 | 2020-12-9 | 47 | 74 |
