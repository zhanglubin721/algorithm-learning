# LC1112 每位学生的最高成绩

Highest Grade For Each Student · Medium · 查询

## 题意

对每个学生返回最高成绩对应的课程与成绩；成绩并列时选课程编号最小的一门，按学生编号排序。

## 表结构

```sql
Create table If Not Exists Enrollments (student_id int, course_id int, grade int);
```

结果需要按题意排序。

## 示例输入

示例1 · Enrollments

| student_id | course_id | grade |
| --- | --- | --- |
| 2 | 2 | 95 |
| 2 | 3 | 95 |
| 1 | 1 | 90 |
| 1 | 2 | 99 |
| 3 | 1 | 80 |
| 3 | 2 | 75 |
| 3 | 3 | 82 |
