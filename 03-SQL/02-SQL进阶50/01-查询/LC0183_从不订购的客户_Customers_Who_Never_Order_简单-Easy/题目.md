# LC183 从不订购的客户

Customers Who Never Order · Easy · 查询

## 题意

找出从未下过订单的客户姓名。

## 表结构

```sql
Create table If Not Exists Customers (id int, name varchar(255));
Create table If Not Exists Orders (id int, customerId int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Customers

| id | name |
| --- | --- |
| 1 | Joe |
| 2 | Henry |
| 3 | Sam |
| 4 | Max |

示例1 · Orders

| id | customerId |
| --- | --- |
| 1 | 3 |
| 2 | 1 |
