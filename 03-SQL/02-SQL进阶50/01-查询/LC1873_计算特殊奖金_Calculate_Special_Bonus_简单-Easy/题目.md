# LC1873 计算特殊奖金

Calculate Special Bonus · Easy · 查询

## 题意

员工编号为奇数且姓名不以M开头时，奖金为全部工资，否则为0；按员工编号排序。

## 表结构

```sql
Create table If Not Exists Employees (employee_id int, name varchar(30), salary int);
```

结果需要按题意排序。

## 示例输入

示例1 · Employees

| employee_id | name | salary |
| --- | --- | --- |
| 2 | Meir | 3000 |
| 3 | Michael | 3800 |
| 7 | Addilyn | 7400 |
| 8 | Juan | 6100 |
| 9 | Kannon | 7700 |
