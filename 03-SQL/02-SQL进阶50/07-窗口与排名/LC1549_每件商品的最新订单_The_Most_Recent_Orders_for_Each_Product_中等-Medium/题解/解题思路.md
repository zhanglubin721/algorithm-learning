### 方法一：等值连接 + 窗口函数

> **思考**
>
> 对每种商品找出日期最新的全部订单。同一天可能有多笔，不能用 $ROW\_NUMBER$ 只留一行，需要并列第一都保留。
>
> 连接 $Orders$ 与 $Products$ 后，按商品分区、按日期降序做 $RANK$。保留 $rk=1$ 的行即可同时拿到所有并列的最近订单，再按名称与编号排序。

我们可以使用等值连接，将 `Orders` 表和 `Products` 表按照 `product_id` 连接起来，然后使用窗口函数 `rank()`，对 `Orders` 表中的每个 `product_id` 进行分组，按照 `order_date` 降序排列，然后取出每个分组中排名第一的记录。

#### MySQL

```sql
# Write your MySQL query statement below
WITH
    T AS (
        SELECT
            *,
            RANK() OVER (
                PARTITION BY product_id
                ORDER BY order_date DESC
            ) AS rk
        FROM
            Orders
            JOIN Products USING (product_id)
    )
SELECT product_name, product_id, order_id, order_date
FROM T
WHERE rk = 1
ORDER BY 1, 2, 3;
```
