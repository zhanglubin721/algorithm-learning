# LC1709 访问日期之间最大的空档期

Biggest Window Between Visits · Medium · 窗口与排名

## 题意

对每位用户，计算相邻两次访问之间的最大天数；还要把最后一次访问到2021-01-01作为一个候选间隔。

## 表结构

```sql
Create table If Not Exists UserVisits(user_id int, visit_date date);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · UserVisits

| user_id | visit_date |
| --- | --- |
| 1 | 2020-11-28 |
| 1 | 2020-10-20 |
| 1 | 2020-12-3 |
| 2 | 2020-10-5 |
| 2 | 2020-12-9 |
| 3 | 2020-11-11 |
