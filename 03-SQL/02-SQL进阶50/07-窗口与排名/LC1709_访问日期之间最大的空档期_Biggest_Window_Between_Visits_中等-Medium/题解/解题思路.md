### 方法一：窗口函数

> **思考**
>
> 每个用户的最大访问间隔等于相邻访问日之差的最大值，最后一次访问还要与 $2021$-$01$-$01$ 比较。
>
> 窗口函数 $\mathrm{LEAD}$ 按 $\textit{user\_id}$ 分区、按日期排序，可取出下一次访问日（缺省为 $2021$-$1$-$1$）。 $\mathrm{DATEDIFF}$ 得到间隔后再按用户取 $\mathrm{MAX}$。

我们可以使用窗口函数 `LEAD` 来获取每个用户每次访问的下一次访问的日期（如果下一次访问的日期不存在，则视为 `2021-1-1`），然后利用 `DATEDIFF` 函数来计算两次访问之间的天数差值，最后对每个用户的天数差值求最大值即可。

#### MySQL

```sql
# Write your MySQL query statement below
WITH
    T AS (
        SELECT
            user_id,
            DATEDIFF(
                LEAD(visit_date, 1, '2021-1-1') OVER (
                    PARTITION BY user_id
                    ORDER BY visit_date
                ),
                visit_date
            ) AS diff
        FROM UserVisits
    )
SELECT user_id, MAX(diff) AS biggest_window
FROM T
GROUP BY 1
ORDER BY 1;
```
