# LC184 部门工资最高的员工

Department Highest Salary · Medium · 窗口与排名

## 题意

返回每个部门工资最高的所有员工；同薪并列者全部保留。

## 表结构

```sql
Create table If Not Exists Employee (id int, name varchar(255), salary int, departmentId int);
Create table If Not Exists Department (id int, name varchar(255));
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Employee

| id | name | salary | departmentId |
| --- | --- | --- | --- |
| 1 | Joe | 70000 | 1 |
| 2 | Jim | 90000 | 1 |
| 3 | Henry | 80000 | 2 |
| 4 | Sam | 60000 | 2 |
| 5 | Max | 90000 | 1 |

示例1 · Department

| id | name |
| --- | --- |
| 1 | IT |
| 2 | Sales |
