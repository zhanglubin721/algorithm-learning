### 方法一：等值连接 + 窗口函数

> **思考**
>
> 为每位顾客列出最近三笔订单，并带上姓名。按人排序后手写取前三行容易在并列日期上出错，窗口函数可在分组内编号。
>
> 先把 $Orders$ 与 $Customers$ 按 $customer\_id$ 连接，再按顾客分区、按 $order\_date$ 降序赋 $ROW\_NUMBER$。保留序号不超过 $3$ 的行，最后按姓名、编号与日期输出。

我们可以使用等值连接，将 `Customers` 表和 `Orders` 表按照 `customer_id` 进行连接，然后使用 `row_number()` 窗口函数来为每个消费者的订单按照 `order_date` 降序排列，并为每个消费者的订单添加一个序号，最后筛选出序号小于等于 $3$ 的订单即可。

#### MySQL

```sql
# Write your MySQL query statement below
WITH
    T AS (
        SELECT
            *,
            ROW_NUMBER() OVER (
                PARTITION BY customer_id
                ORDER BY order_date DESC
            ) AS rk
        FROM
            Orders
            JOIN Customers USING (customer_id)
    )
SELECT name AS customer_name, customer_id, order_id, order_date
FROM T
WHERE rk <= 3
ORDER BY 1, 2, 4 DESC;
```
