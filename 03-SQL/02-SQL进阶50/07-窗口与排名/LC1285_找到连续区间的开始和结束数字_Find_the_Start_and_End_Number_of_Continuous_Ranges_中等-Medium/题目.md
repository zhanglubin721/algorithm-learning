# LC1285 找到连续区间的开始和结束数字

Find the Start and End Number of Continuous Ranges · Medium · 窗口与排名

## 题意

把Logs中连续的log_id合并成区间，返回每个区间的起止编号。

## 表结构

```sql
Create table If Not Exists Logs (log_id int);
```

结果需要按题意排序。

## 示例输入

示例1 · Logs

| log_id |
| --- |
| 1 |
| 2 |
| 3 |
| 7 |
| 8 |
| 10 |
