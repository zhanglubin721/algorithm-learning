# LC1270 向公司 CEO 汇报工作的所有人

All People Report to the Given Manager · Medium · 递归与连续区间

## 题意

找出所有直接或间接向employee_id为1的经理汇报的员工，不包含经理本人。

## 表结构

```sql
Create table If Not Exists Employees (employee_id int, employee_name varchar(30), manager_id int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Employees

| employee_id | employee_name | manager_id |
| --- | --- | --- |
| 1 | Boss | 1 |
| 3 | Alice | 3 |
| 2 | Bob | 1 |
| 4 | Daniel | 2 |
| 7 | Luis | 4 |
| 8 | John | 3 |
| 9 | Angela | 8 |
| 77 | Robert | 1 |
