### 方法一：合并 + 窗口函数 + 分组求最大最小值

> **思考**
>
> 成功与失败分属两表，连续区间却要按同一时间轴拼接。先把 $2019$ 年的失败、成功日期并成带状态的事件流。
>
> 同一状态的连续日期与其组内名次之差为常数，该差可作为岛标识。按状态与该标识分组，取最小、最大日期即一段连续区间。
>
> $UNION\ ALL$ 对齐两表， $RANK$ 制造岛键， $GROUP\ BY$ 收成区间。

我们可以将两个表合并，用一个字段 $st$ 表示状态，其中 `failed` 表示失败，`succeeded` 表示成功。然后我们可以使用窗口函数，将相同状态的记录分到一组，求出每个日期与其所在组排名的差值 $pt$，作为同一个连续状态的标识。最后我们可以按照 $st$ 和 $pt$ 分组，求出每组的最小日期和最大日期，然后按照最小日期排序即可。

#### MySQL

```sql
# Write your MySQL query statement below
WITH
    T AS (
        SELECT fail_date AS dt, 'failed' AS st
        FROM Failed
        WHERE YEAR(fail_date) = 2019
        UNION ALL
        SELECT success_date AS dt, 'succeeded' AS st
        FROM Succeeded
        WHERE YEAR(success_date) = 2019
    )
SELECT
    st AS period_state,
    MIN(dt) AS start_date,
    MAX(dt) AS end_date
FROM
    (
        SELECT
            *,
            SUBDATE(
                dt,
                RANK() OVER (
                    PARTITION BY st
                    ORDER BY dt
                )
            ) AS pt
        FROM T
    ) AS t
GROUP BY 1, pt
ORDER BY 2;
```
