# LC1225 报告系统状态的连续日期

Report Contiguous Dates · Hard · 递归与连续区间

## 题意

只考虑2019年的日期，把连续成功或连续失败的日期合并成区间，输出状态、开始和结束日期并按开始日期排序。

## 表结构

```sql
Create table If Not Exists Failed (fail_date date);
Create table If Not Exists Succeeded (success_date date);
```

结果需要按题意排序。

## 示例输入

示例1 · Failed

| fail_date |
| --- |
| 2018-12-28 |
| 2018-12-29 |
| 2019-01-04 |
| 2019-01-05 |

示例1 · Succeeded

| success_date |
| --- |
| 2018-12-30 |
| 2018-12-31 |
| 2019-01-01 |
| 2019-01-02 |
| 2019-01-03 |
| 2019-01-06 |
