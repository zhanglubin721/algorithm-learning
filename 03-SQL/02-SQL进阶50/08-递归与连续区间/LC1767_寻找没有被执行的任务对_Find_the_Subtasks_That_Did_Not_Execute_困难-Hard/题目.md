# LC1767 寻找没有被执行的任务对

Find the Subtasks That Did Not Execute · Hard · 递归与连续区间

## 题意

每个任务应有从1到subtasks_count编号的子任务，返回其中没有出现在Executed表中的子任务。

## 表结构

```sql
Create table If Not Exists Tasks (task_id int, subtasks_count int);
Create table If Not Exists Executed (task_id int, subtask_id int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Tasks

| task_id | subtasks_count |
| --- | --- |
| 1 | 3 |
| 2 | 2 |
| 3 | 4 |

示例1 · Executed

| task_id | subtask_id |
| --- | --- |
| 1 | 2 |
| 3 | 1 |
| 3 | 2 |
| 3 | 3 |
| 3 | 4 |
