# LC1747 应该被禁止的 Leetflex 账户

Leetflex Banned Accounts · Medium · 子查询

## 题意

找出曾在两个不同IP地址上存在重叠登录时间段的账户；端点重合也算重叠。

## 表结构

```sql
Create table If Not Exists LogInfo (account_id int, ip_address int, login datetime, logout datetime);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。
