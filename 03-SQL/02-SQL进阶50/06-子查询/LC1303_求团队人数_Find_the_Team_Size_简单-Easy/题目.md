# LC1303 求团队人数

Find the Team Size · Easy · 子查询

## 题意

为每位员工输出其所在团队的人数。

## 表结构

```sql
Create table If Not Exists Employee (employee_id int, team_id int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Employee

| employee_id | team_id |
| --- | --- |
| 1 | 8 |
| 2 | 8 |
| 3 | 8 |
| 4 | 7 |
| 5 | 9 |
| 6 | 9 |
