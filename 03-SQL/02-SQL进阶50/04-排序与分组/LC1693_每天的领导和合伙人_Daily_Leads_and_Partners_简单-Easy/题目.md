# LC1693 每天的领导和合伙人

Daily Leads and Partners · Easy · 排序与分组

## 题意

按日期和品牌分别统计不同潜在客户与不同合作伙伴的数量。

## 表结构

```sql
Create table If Not Exists DailySales(date_id date, make_name varchar(20), lead_id int, partner_id int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。
