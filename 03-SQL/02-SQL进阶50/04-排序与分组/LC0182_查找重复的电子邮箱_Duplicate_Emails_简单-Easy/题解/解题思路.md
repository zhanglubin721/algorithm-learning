### 方法一：分组统计

> **思考**
>
> 找出出现超过一次的邮箱。按 $\textit{email}$ 分组后用 $\textit{HAVING}\,\textit{COUNT}>1$ 留下重复项，语义就是「出现次数」。

我们可以使用 `GROUP BY` 语句，按照 `email` 字段进行分组，然后使用 `HAVING` 语句，筛选出现次数大于 $1$ 的 `email`。

#### MySQL

```sql
# Write your MySQL query statement below
SELECT email
FROM Person
GROUP BY 1
HAVING COUNT(1) > 1;
```
