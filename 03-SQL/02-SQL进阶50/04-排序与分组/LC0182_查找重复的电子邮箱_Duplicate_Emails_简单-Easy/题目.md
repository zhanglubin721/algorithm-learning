# LC182 查找重复的电子邮箱

Duplicate Emails · Easy · 排序与分组

## 题意

找出至少出现两次的电子邮箱地址，每种邮箱只输出一次。

## 表结构

```sql
Create table If Not Exists Person (id int, email varchar(255));
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Person

| id | email |
| --- | --- |
| 1 | a@b.com |
| 2 | c@d.com |
| 3 | a@b.com |
