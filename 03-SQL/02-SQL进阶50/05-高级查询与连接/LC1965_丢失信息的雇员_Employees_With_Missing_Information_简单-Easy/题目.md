# LC1965 丢失信息的雇员

Employees With Missing Information · Easy · 高级查询与连接

## 题意

找出只有姓名记录或只有工资记录、而另一张表缺少对应记录的员工编号，按编号升序输出。

## 表结构

```sql
Create table If Not Exists Employees (employee_id int, name varchar(30));
Create table If Not Exists Salaries (employee_id int, salary int);
```

结果需要按题意排序。

## 示例输入

示例1 · Employees

| employee_id | name |
| --- | --- |
| 2 | Crew |
| 4 | Haven |
| 5 | Kristian |

示例1 · Salaries

| employee_id | salary |
| --- | --- |
| 5 | 76071 |
| 1 | 22517 |
| 4 | 63539 |
