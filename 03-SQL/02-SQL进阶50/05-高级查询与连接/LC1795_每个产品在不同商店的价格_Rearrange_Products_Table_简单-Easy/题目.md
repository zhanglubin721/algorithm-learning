# LC1795 每个产品在不同商店的价格

Rearrange Products Table · Easy · 高级查询与连接

## 题意

把Products的三个商店价格列转换成长表，每个非NULL价格输出产品编号、商店名和价格。

## 表结构

```sql
Create table If Not Exists Products (product_id int, store1 int, store2 int, store3 int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Products

| product_id | store1 | store2 | store3 |
| --- | --- | --- | --- |
| 0 | 95 | 100 | 105 |
| 1 | 70 | NULL | 80 |
