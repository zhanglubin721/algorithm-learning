### 方法一：自连接

> **思考**
>
> 一维最短距离即任意两点差的最小正值。点数不多时，自连接 `p1.x < p2.x` 后取 `MIN(差)` 即可。

我们可以使用自连接，将表中的每个点与其他更大的点进行连接，然后计算两点之间的距离，最后取最小值。

#### MySQL

```sql
# Write your MySQL query statement below
SELECT MIN(p2.x - p1.x) AS shortest
FROM
    Point AS p1
    JOIN Point AS p2 ON p1.x < p2.x;
```
