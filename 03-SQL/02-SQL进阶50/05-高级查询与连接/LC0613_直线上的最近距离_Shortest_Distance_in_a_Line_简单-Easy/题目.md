# LC613 直线上的最近距离

Shortest Distance in a Line · Easy · 高级查询与连接

## 题意

一维坐标轴上的点互不相同，返回任意两点之间的最短距离。

## 表结构

```sql
Create Table If Not Exists Point (x int not null);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Point

| x |
| --- |
| -1 |
| 0 |
| 2 |
