# LC603 连续空余座位

Consecutive Available Seats · Easy · 高级查询与连接

## 题意

找出至少与一个相邻空座构成连续空座段的座位编号，按座位编号排序。

## 表结构

```sql
Create table If Not Exists Cinema (seat_id int primary key auto_increment, free bool);
```

结果需要按题意排序。

## 示例输入

示例1 · Cinema

| seat_id | free |
| --- | --- |
| 1 | 1 |
| 2 | 0 |
| 3 | 1 |
| 4 | 1 |
| 5 | 1 |
