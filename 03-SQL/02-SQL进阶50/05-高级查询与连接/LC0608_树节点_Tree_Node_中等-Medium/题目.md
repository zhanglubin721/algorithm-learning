# LC608 树节点

Tree Node · Medium · 高级查询与连接

## 题意

根据树节点及父节点关系，分别把节点标为Root、Inner或Leaf。

## 表结构

```sql
Create table If Not Exists Tree (id int, p_id int);
```

未明确规定顺序的结果按无序行比较，但保留重复行数量。

## 示例输入

示例1 · Tree

| id | p_id |
| --- | --- |
| 1 | NULL |
| 2 | 1 |
| 3 | 1 |
| 4 | 2 |
| 5 | 2 |

示例2 · Tree

| id | p_id |
| --- | --- |
| 1 | NULL |
