# IDEA 算法与 SQL 学习工程

本工程用于在 IDEA 中按题单练习：运行题目的 Start，创建带时间记录的副本，在副本里作答，测试、调试、复做，并导出独立 AI 复核材料。

已包含面试经典150、Hot100、SQL基础50、SQL进阶50，共350个题单位置、283道不同题目。算法183道，SQL100道。题面为本工程整理的说明、接口、约束和示例；题解使用注明许可与来源的开源参考，不冒充力扣官方题解。

## 第一次使用

1. 在 IDEA 打开当前目录或 `pom.xml`，项目 SDK 选择 **JDK 21**。本机已发现可用的 GraalVM JDK 21；终端默认Java是8，工程脚本在macOS会自动选择21，不修改系统默认值。
2. 使用 IDEA 左侧的 **Project** 视图，进入三大题单目录，选择题目。
3. 打开该题 `入口/src/main/java/.../Start.java`，点击main方法旁的运行按钮。
4. 在控制台选择 `1`，程序生成本轮副本并开始计时。复制控制台给出的路径打开 `Solution.java` 或 `answer.sql`，在副本里写答案。
5. 保存文件后回到控制台选 `3` 测试，选 `5` 结束并登记独立/提示/题解/未完成。

不想先处理IDEA配置时，也可在工程终端运行：

```bash
./tools/start.sh 1
```

这会编译公共引擎并开始LC1练习。命令行入口按题号选择首个题单位置；IDEA里每个题单位置都有自己的Start。

## 控制台操作

| 操作 | 行为 |
|---|---|
| 1 开始新一轮 | 从固定模板生成新的副本，不覆盖历史；记录创建时间和版本哈希 |
| 2 继续 | 继续未完成的一轮；异常中断后可补录丢失的有效分钟 |
| 3 测试 | 只编译并运行当前轮，不编译其他未写完的作答 |
| 4 暂停/恢复 | 主动暂停期间不计有效用时 |
| 5 结束 | 冻结本轮用时，登记完成方式；当前代码和用例必须对应通过记录 |
| 6 历史 | 查看本题此题单位置的历史记录；跨题单汇总见progress |
| 7 AI复核 | 生成题号、题意、当前代码和测试记录，不夹带参考答案 |
| 8 调试 | Java启动独立JVM并等待5005端口连接；选择IDEA的Attach-练习配置 |
| 0 退出 | 保存并暂停当前轮，刷新进度 |

`作答/src/main/java/.../attempts/`下每个目录就是一轮。支持直接删除某轮后重新开始，推荐保留历史以观察进步。模板和题解不受复做影响。

计时分别保存总经过时间、主动计时区间累积、首次本地通过时间。无需一直运行一个额外网页。异常退出的最后一段不会被假定精确，继续时提示补录。源码头部记录创建时间，`session.json`保存完整状态。

## 测试如何保证可靠

先看[测试质量报告](progress/测试质量报告.md)。本地通过只代表通过这些本地用例，不表示官方AC，也不自动表示本人已掌握。

算法测试包含公开示例、约束内边界、固定种子的随机构造、独立Python预期、部分最大规模数据，以及树/链表身份和多答案判定。原地修改、图/随机链表深拷贝、拓扑序、最长回文等使用对应规则，不能只打印答案比较字符串。

参考实现已逐题编译运行；另外用常量错误返回及边界变异检验用例是否能发现错误。仍然存在未被有限测试覆盖的可能，尤其是复杂度、概率均匀性和参考实现之间的共同错误。质量报告列明独立预期与参考预期的数量，保存发现并修复的测试漏洞。

每轮可直接把 `AI复核材料.md` 交给另一个AI，要求独立推理、构造反例、分析时间空间复杂度。参考答案不是复核包的一部分。

## SQL连接本机MySQL8

你目前尚未安装MySQL，所以SQL运行尚未进行实库验证；所有题目的表结构、示例/构造数据、参考查询和判定流程已经准备。算法不依赖MySQL。

安装MySQL8之后：

1. 创建专用数据库 `algorithm_practice`，准备仅用于练习的账号。
2. 将 `config/mysql.example.properties` 复制成 `config/mysql.local.properties`，填写host、port、database、username。密码填写在该本机文件，或通过 `MYSQL_PASSWORD` 环境变量提供。
3. 测试器为每次查询创建唯一的 `algorithm_practice_case_…` 子库，使用完即删除；账号需要对这个练习命名范围具有建库、建表、读写、清理权限。不要配置工作数据库账号。
4. 在题目副本中填写 `answer.sql`，控制台选 `3`。第一次运行会显示实际MySQL版本；仅接受MySQL8主版本。

使用独立子库而不是连接级临时表，是因为MySQL同一个临时表不能可靠支持本题库所需的多次引用和自连接。测试只清理本次程序成功创建的随机子库，已有基础库与其他数据库不会被DROP。

每个用例将参考查询与固定预期交叉检查，再比较用户查询。固定预期与参考结果不一致时输出 `ORACLE_DISAGREEMENT`，不会判用户通过。部分扩展用例由参考查询提供运行时预期，质量报告会说明；不能把这部分等同于独立预期。

结果按列名对齐，列名不区分大小写，保留重复行和NULL。题目要求排序时比较行序，否则比较多重集。LC196允许DELETE，其他题使用单条SELECT/WITH。MySQL JDBC 8.4.0已放入项目缓存并校验，Maven也声明了对应依赖。

## IDEA与构建说明

学习目录和Java包路径分开：中文题名目录下有固定的源码根，包名使用英文。每轮有独立包名，避免Solution类冲突。

作答源码保留索引、代码补全与断点映射，但排除常规项目编译；公共引擎通过JDK编译器只编译当前作答。不要把作答目录整体标为Excluded，否则IDEA代码补全会失效。`.idea/compiler.xml`和Maven includes规则已经配置。

调试时先在当前副本打断点，选控制台 `8`，然后运行项目的 `Attach-练习` 调试配置。测试进程最长等待10分钟。普通运行使用独立JVM、256MB堆和30秒整套用例超时，单路标准输出/错误输出各限制约1MB，避免死循环打印占满磁盘。这里不构成不可信代码安全沙箱，只用于你自己的练习代码。

源码或测试用例修改后，旧通过记录不会继续算作当前版本通过。删除练习后，再退出一次启动器，或运行 `engine.Progress` 刷新进度。

## 工程验证命令

```bash
./tools/compile.sh
# 使用JDK21运行以下类，或者在IDEA运行main
java -cp .cache/engine engine.SelfTest
```

Maven Wrapper可用；本机已有Maven也可以执行：

```bash
./mvnw -s tools/maven-settings.xml -DskipTests compile
```

macOS的mvnw会选择JDK21；其他系统设置 `ALGORITHM_JAVA_HOME` 或 `JAVA_HOME` 指向JDK21。项目依赖缓存保存在`.cache`，不需要改全局Maven镜像设置。

维护脚本在 `tools/`，日常刷题不需要重新导入、重新生成题库或跑全部参考校验。
