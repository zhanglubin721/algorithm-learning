# LC287 寻找重复数

Find the Duplicate Number · Medium · 技巧

## 题意

长度为n+1的数组只包含1到n之间的值，存在唯一重复数，求它；不能修改数组并限制额外空间。

## 约束要点

- 1 <= n <= 105
- 1 <= nums[i] <= n

```text

```
