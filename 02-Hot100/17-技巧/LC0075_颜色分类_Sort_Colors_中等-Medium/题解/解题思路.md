### 方法一：三指针

> **思考**
>
> 统计 $0$、 $1$、 $2$ 的个数再覆写需要两趟扫描；直接排序也能得到结果， $n \le 300$ 时间足够。题目不允许使用库函数排序，进阶还要求一趟扫描且仅用常数额外空间。
>
> 数组中只有三个取值，需要划分成「全 $0$ / 全 $1$ / 全 $2$」三段。为此用 $i$、 $j$ 分别框住已经归位的 $0$ 与 $2$， $k$ 扫描未知区间。与 $2$ 交换时，换回来的元素尚未考察，因此 $k$ 不能前进；与 $0$ 交换时，换回来的元素来自已扫描区间，因此 $k$ 可以同步右移。一遍结束后三段自然有序。

我们定义三个指针 $i$, $j$ 和 $k$，其中指针 $i$ 用于指向数组中元素值为 $0$ 的最右边界，指针 $j$ 用于指向数组中元素值为 $2$ 的最左边界，初始时 $i=-1$, $j=n$。指针 $k$ 用于指向当前遍历的元素，初始时 $k=0$。

当 $k \lt j$ 时，我们执行如下操作：

- 若 $nums[k]=0$，则将其与 $nums[i+1]$ 交换，然后 $i$ 和 $k$ 都加 $1$；
- 若 $nums[k]=2$，则将其与 $nums[j-1]$ 交换，然后 $j$ 减 $1$；
- 若 $nums[k]=1$，则 $k$ 加 $1$。

遍历结束后，数组中的元素就被分成了 $[0,i]$, $[i+1,j-1]$ 和 $[j,n-1]$ 三个部分。

时间复杂度 $O(n)$，其中 $n$ 是数组的长度。只需要遍历一遍数组即可。空间复杂度 $O(1)$。

#### Java

```java
class Solution {
    public void sortColors(int[] nums) {
        int i = -1, j = nums.length, k = 0;
        while (k < j) {
            if (nums[k] == 0) {
                swap(nums, ++i, k++);
            } else if (nums[k] == 2) {
                swap(nums, --j, k);
            } else {
                ++k;
            }
        }
    }

    private void swap(int[] nums, int i, int j) {
        int t = nums[i];
        nums[i] = nums[j];
        nums[j] = t;
    }
}
```
