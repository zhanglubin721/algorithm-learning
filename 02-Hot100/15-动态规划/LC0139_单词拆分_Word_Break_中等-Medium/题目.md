# LC139 单词拆分

Word Break · Medium · 动态规划

## 题意

判断字符串是否能完整分割成词典中的单词，词典中的同一个词可以重复使用。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;
```

输入依次为：s（string）, wordDict（list<string>）。

## 约束要点

- 1 <= s.length <= 300
- 1 <= wordDict.length <= 1000
- 1 <= wordDict[i].length <= 20
- wordDict 中的所有字符串 互不相同

## 示例输入

示例1

```text
"leetcode"
["leet","code"]
```

示例2

```text
"applepenapple"
["apple","pen"]
```

示例3

```text
"catsandog"
["cats","dog","sand","and","cat"]
```
