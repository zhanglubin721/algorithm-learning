# LC146 LRU 缓存

LRU Cache · Medium · 链表

## 题意

实现固定容量LRU缓存。get命中和put均更新最近使用关系，超容量时淘汰最久未使用项，平均操作复杂度O(1)。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;
class LRUCache {

    public LRUCache(int capacity) { throw new UnsupportedOperationException("TODO"); }
    
    public int get(int key) { throw new UnsupportedOperationException("TODO"); }
    
    public void put(int key, int value) { throw new UnsupportedOperationException("TODO"); }
}
```

输入依次为：inputs（integer[]）, inputs（integer[]）。

## 约束要点

- 1 <= capacity <= 3000
- 0 <= key <= 10000
- 0 <= value <= 105

## 示例输入

示例1

```text
["LRUCache","put","put","get","put","get","put","get","get","get"]
[[2],[1,1],[2,2],[1],[3,3],[2],[4,4],[1],[3],[4]]
```
