# LC234 回文链表

Palindrome Linked List · Easy · 链表

## 题意

判断单链表的节点值序列是否为回文。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;

class Solution {
    public boolean isPalindrome(ListNode head) { throw new UnsupportedOperationException("TODO"); }
}
```

输入依次为：head（ListNode）。

## 约束要点

- 链表中节点数目在范围[1, 105] 内
- 0 <= Node.val <= 9

## 示例输入

示例1

```text
[1,2,2,1]
```

示例2

```text
[1,2]
```
