# LC138 随机链表的复制

Copy List with Random Pointer · Medium · 链表

## 题意

深拷贝含next与random指针的链表；random可以为空或指向任意节点，复制结果不得引用原节点。

## 约束要点

- random_index：随机指针指向的节点索引（范围从 0 到 n-1）；如果不指向任何节点，则为  null 。
- 0 <= n <= 1000
- -104 <= Node.val <= 104

## 示例输入

示例1

```text
[[7,null],[13,0],[11,4],[10,2],[1,0]]
```

示例2

```text
[[1,1],[2,1]]
```

示例3

```text
[[3,null],[3,0],[3,null]]
```
