# LC48 旋转图像

Rotate Image · Medium · 矩阵

## 题意

把方形矩阵原地顺时针旋转90度，不能用另一张矩阵代替原地修改。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;
class Solution {
    public void rotate(int[][] matrix) { throw new UnsupportedOperationException("TODO"); }
}
```

输入依次为：matrix（integer[][]）。

## 约束要点

- 1 <= n <= 20
- -1000 <= matrix[i][j] <= 1000

## 示例输入

示例1

```text
[[1,2,3],[4,5,6],[7,8,9]]
```

示例2

```text
[[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
```
