# LC73 矩阵置零

Set Matrix Zeroes · Medium · 矩阵

## 题意

矩阵中某格为0时，其整行和整列都要变为0。基于原始0的位置进行原地修改。

## 约束要点

- 1 <= m, n <= 200
- -231 <= matrix[i][j] <= 231 - 1

## 示例输入

示例1

```text
[[1,1,1],[1,0,1],[1,1,1]]
```

示例2

```text
[[0,1,2,0],[3,4,5,2],[1,3,1,5]]
```
