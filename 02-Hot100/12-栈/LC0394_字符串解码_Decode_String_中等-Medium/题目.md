# LC394 字符串解码

Decode String · Medium · 栈

## 题意

解析k[内容]形式的重复编码，编码可以嵌套，返回展开后的字符串。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;

```

输入依次为：s（string）。

## 约束要点

- 1 <= s.length <= 30
- s 保证是一个 有效 的输入。
- s 中所有整数的取值范围为 [1, 300]

## 示例输入

示例1

```text
"3[a]2[bc]"
```

示例2

```text
"3[a2[c]]"
```

示例3

```text
"2[abc]3[cd]ef"
```
