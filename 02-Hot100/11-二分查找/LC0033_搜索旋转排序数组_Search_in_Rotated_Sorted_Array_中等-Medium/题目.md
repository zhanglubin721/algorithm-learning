# LC33 搜索旋转排序数组

Search in Rotated Sorted Array · Medium · 二分查找

## 题意

严格递增数组经过旋转，查找目标并返回下标，不存在则为-1；要求对数时间。

## 约束要点

- 1 <= nums.length <= 5000
- -104 <= nums[i] <= 104
- 题目数据保证 nums 在预先未知的某个下标上进行了旋转
- -104 <= target <= 104

## 示例输入

示例1

```text
[4,5,6,7,0,1,2]
0
```

示例2

```text
[4,5,6,7,0,1,2]
3
```

示例3

```text
[1]

```
