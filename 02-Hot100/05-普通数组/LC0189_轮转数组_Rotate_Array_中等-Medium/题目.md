# LC189 轮转数组

Rotate Array · Medium · 普通数组

## 题意

原地把数组向右旋转k步，处理k大于长度和k为0的情况。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;
class Solution {
    public void rotate(int[] nums, int k) { throw new UnsupportedOperationException("TODO"); }
}
```

输入依次为：nums（integer[]）, k（integer）。

## 约束要点

- 1 <= nums.length <= 105
- -231 <= nums[i] <= 231 - 1
- 0 <= k <= 105

## 示例输入

示例1

```text
[1,2,3,4,5,6,7]
3
```

示例2

```text
[-1,-100,3,99]
2
```
