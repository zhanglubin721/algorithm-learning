# LC55 跳跃游戏

Jump Game · Medium · 贪心算法

## 题意

从数组首位置出发，每个元素限制向右跳跃的最大距离，判断能否到达最后位置。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;
class Solution {
    public boolean canJump(int[] nums) { throw new UnsupportedOperationException("TODO"); }
}
```

输入依次为：nums（integer[]）。

## 约束要点

- 1 <= nums.length <= 104
- 0 <= nums[i] <= 105

## 示例输入

示例1

```text
[2,3,1,1,4]
```

示例2

```text
[3,2,1,0,4]
```
