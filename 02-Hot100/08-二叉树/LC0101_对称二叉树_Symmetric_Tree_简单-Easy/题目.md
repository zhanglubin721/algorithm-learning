# LC101 对称二叉树

Symmetric Tree · Easy · 二叉树

## 题意

判断二叉树是否关于根节点左右镜像对称。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;
```

## 约束要点

- 树中节点数目在范围 [1, 1000] 内
- -100 <= Node.val <= 100

## 示例输入

示例1

```text
[1,2,2,3,4,4,3]
```

示例2

```text
[1,2,2,null,3,null,3]
```
