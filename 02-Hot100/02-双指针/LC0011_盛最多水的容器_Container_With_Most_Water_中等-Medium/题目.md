# LC11 盛最多水的容器

Container With Most Water · Medium · 双指针

## 题意

数组下标表示竖线的位置，元素表示高度。选择两条竖线，求能围成的最大盛水面积。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;
class Solution {

}
```

输入依次为：height（integer[]）。

## 约束要点

- 2 <= n <= 105
- 0 <= height[i] <= 104

## 示例输入

示例1

```text
[1,8,6,2,5,4,8,3,7]
```

示例2

```text
[1,1]
```
