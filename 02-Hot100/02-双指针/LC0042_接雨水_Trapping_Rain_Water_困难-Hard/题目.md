# LC42 接雨水

Trapping Rain Water · Hard · 双指针

## 题意

柱子宽度均为1，数组给出高度。计算下雨后柱子之间能够积存的总水量。

## 作答接口

```java
import java.util.*;
import java.util.stream.*;
class Solution {
    public int trap(int[] height) { throw new UnsupportedOperationException("TODO"); }
}
```

输入依次为：height（integer[]）。

## 约束要点

- 1 <= n <= 2 * 104
- 0 <= height[i] <= 105

## 示例输入

示例1

```text
[0,1,0,2,1,0,1,3,2,1,2,1]
```

示例2

```text
[4,2,0,3,2,5]
```
